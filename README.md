# Consultancy Website Template

A modern, responsive consultancy website template built with Bootstrap 5.

## Features
- Fully responsive design
- Clean and modern UI
- Easy to customize
- Built with Bootstrap 5
- Cross-browser compatible
- Fast loading and optimized

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Start customizing the content in the HTML files

## Customization
- Update the color scheme in `css/style.css`
- Replace images in the `img/` directory
- Modify content in the HTML files
